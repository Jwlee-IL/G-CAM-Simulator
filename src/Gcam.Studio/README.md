# Gcam.Studio — WPF shell (net9.0-windows)

Views, custom controls, converters, theme dictionaries, WPF-bound services and the DI composition root.
No business logic: views bind to ViewModels in `Gcam.Studio.Core`, and code-behind only calls
`InitializeComponent()`.

| Folder | Contents | Docs |
|---|---|---|
| `Views/` | `MainWindow` — borderless window with a themed caption (no OS title bar), fixed grid, flexible centre, left Scene / Optics / Detector tabs, the Imaging measurements panel (Pan / Distance / Angle / ROI icon toggles with window key bindings Alt+P / D / A / R, a delete button per row), one-line status bar (run status or a refused Start, Options summary, acquisition or readout-preparation progress); Imaging, Spectrum, Waveform and Detector centre / right-panel templates (`*View`, `*Panel`, `ImagingOptionsPanel`, `FocusSweepView`); `ReadoutPanel` (the left Detector tab: readout mode, calibration lines, Prepare, energy window); `ReadoutDetectorView` / `ReadoutWaveformView` (the physical-readout view tabs) and `EmptyReadoutState` (shown in those tabs under `DirectCrystal`); `OptionsView` (the Options dialog in the modal layer) | [DESIGN.ViewLayer](../../docs/DESIGN.ViewLayer.md), [DESIGN.Layout](../../docs/DESIGN.Layout.md) |
